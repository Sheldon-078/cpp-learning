# Thread Pool

## V0.1 Features
支持创建拥有多个线程的线程池，可以向线程池的任务队列中提交任务，然后让多个池中的线程来处理任务。停止信号变为true后，就开始关闭线程池的准备操作，当任务队列中的所有任务全部完成后，线程池析构。
## Design
worker通过对任务队列加锁来取任务，如果任务队列中有任务或者stop信号为ture,则继续执行，反之则陷入休眠。没有任务时会释放mutex，等待放入任务之后notify。
shutdown会检查任务队列中是否还有任务，有过有就继续执行，直到任务为空才会return。
## Correctness Tests
今天测试了以下几种情况：
1.通过看输出是否执行了正确次数
2.0个任务时线程池能否正确退出
3.只有一个worker，但有多个任务时能否正确工作
4.每个任务是否都被正确执行一遍
